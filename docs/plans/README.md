# Plans

Plans generated by the `plan-feature` skill from the issues (`YYYY-MM-DD-<slug>.md`). Each plan states its issue, phase and base branch, and `implement-plan` checks off its tasks.

**Only the five most recent plans are kept here**, the current one included. Older plans are removed when a new one is added: they stay in the git history and as a comment on their issue (decided by the user on 2026-11-17).

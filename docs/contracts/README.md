# Back ↔ web contracts

One contract per feature that touches back and web (`<slug>.md`), created in task **T0** of `/implement-plan-team` from [the template](../../.claude/skills/implement-plan-team/assets/contract-template.md).

Each contract covers the application service, the commands and views, the errors and their translation, the OpenAPI fragment and the screens. The `backend-dev` and `web-dev` agents agree on it, it is frozen in a commit and every renegotiation is recorded in its "Changes" section. See [ADR 0007](../adr/0007-equipo-back-web-contrato-primero.md).
